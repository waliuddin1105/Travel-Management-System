<h1 align="center">🌍 Travel Management System (C++)</h1>

<p align="center">
  <b>A console-based travel management system written in C++ that handles customer registration, cab booking, hotel booking, and billing operations.</b>
</p>

<hr>

<h2>📖 Overview</h2>
<p>
  The <b>Travel Management System</b> is a menu-driven C++ project designed to automate and simplify travel-related tasks. 
  It allows users to register customers, book cabs and hotels, and generate detailed billing receipts — all through a simple text-based interface.
</p>

<hr>

<h2>🧩 Features</h2>
<ul>
  <li>👤 <b>Customer Management</b> – Register and store customer details using file handling.</li>
  <li>🚕 <b>Cab Booking</b> – Choose cab types, calculate fares, and handle multiple trips.</li>
  <li>🏨 <b>Hotel Booking</b> – Select from available hotels and services with automatic charge calculation.</li>
  <li>🧾 <b>Billing System</b> – Generate and display complete receipts including all charges.</li>
  <li>💾 <b>Data Persistence</b> – Uses file handling to store customer and booking data.</li>
  <li>⚙️ <b>Object-Oriented Design</b> – Modular structure using C++ classes and templates.</li>
</ul>

<hr>

<h2>🏗️ Technologies Used</h2>
<ul>
  <li>C++ (OOP, File Handling, Exception Handling)</li>
  <li>Standard Template Library (STL)</li>
  <li>Text-based Console UI</li>
</ul>
