Pak Travels Management System
Pak Travels is a simple console-based travel management system developed in C++. It allows users to manage customers, cab rentals, hotel bookings, and generate bills.

Features:
Customer Management:
Add new customers and view previous customer records stored in a file.

Cab Management:
Rent standard or luxury cabs with cost calculation based on kilometers traveled.

Hotel Booking:
Choose from multiple hotels and packages with associated costs.

Charges and Billing:
Generate and display receipts combining cab and hotel expenses.

How to Use:
Run the program.

Enter your name to proceed.

Use the main menu to navigate:

Manage customers

Rent cabs

Book hotels

Generate and view your bill

Follow on-screen instructions to input required data.

Technologies Used:
C++ (Standard libraries and file handling)

Windows system calls (system("cls"), system("color") for console UI enhancements)

File Structure:
Old_customers.txt — Stores customer details persistently.

receipt.txt — Stores generated receipts.

Notes:
The program also uses basic error handling for invalid inputs.

Designed for Windows console environments.
