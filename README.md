Pak Travels Management System
Pak Travels is a simple console-based travel management system developed in C++. It allows users to manage customers, cab rentals, hotel bookings, and generate bills.

Features
Customer Management
Add new customers and view previous customer records stored in a file.

Cab Management
Rent standard or luxury cabs with cost calculation based on kilometers traveled.

Hotel Booking
Choose from multiple hotels and packages with associated costs.

Charges and Billing
Generate and display receipts combining cab and hotel expenses.
